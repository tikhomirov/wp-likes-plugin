# 1.1.0: лайки только по POST, без GET-ссылок для роботов

## Резюме

Кнопка лайка отдавала `<a href=".../admin-ajax.php?action=process_simple_like&post_id=&nonce=&disabled=true">`.
Обработчик читал `$_REQUEST`, поэтому GET от краулера с живым nonce увеличивал счётчик.
Просмотры на rwsite считаются отдельным AJAX, поэтому у статей лайков могло стать больше, чем просмотров.

## План

1. Убрать href у кнопки (`role="button"`, `rel="nofollow"`), в RSS кнопку не выводить.
2. Принимать только POST с nonce; отклонять GET и известные bot UA.
3. Удалить ветку `disabled=true` (no-JS GET), которая задумывалась как запасной лайк.
4. Поднять версию до 1.1.0, обновить ассеты.
